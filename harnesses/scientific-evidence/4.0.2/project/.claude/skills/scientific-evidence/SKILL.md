# 共享科研证据分析

版本：4.0.2。类型：科研分析 Workflow。创建：2026-10-16；更新：2026-10-21。输出：当前任务公共契约指定的交付目录。

## 目标与完成标准

从当前原始数据交付回答研究问题、经实际计算和独立质疑后仍有支持、可复现且适用范围明确的结论。下列标准适用于实际结果；缺口须明确记录，不能以完成清单代替。

- **公开问题覆盖完整。** 主侧的问题覆盖记录逐项连接研究目标、可估计比较、定义与基准、执行证据和当前结论。每个实质问题已回答，或有数据/工具依据说明尚未解决及其影响；一个显著结果或若干 Finding 不能代表完整覆盖。方向、幅度、变化过程与不确定性按问题需要量化，不能全部替换成显著性判断。
- **验证类型真实。** 复算、重跑、敏感性、分组描述和分离证据验证分别留证。声称留出泛化的主张有组/样本成员、零重叠检查、结果前固定的形成规则和实际测试结果；未使用的组身份或另一执行者不自动构成分离。公共目标要求的验证不能被静默省略，不可行时给出设计证据并限制结论。
- **竞争解释经实际比较。** 对最可能改变核心判断且现有资源可检验的解释，保存不同预测、可比基线、区分性检验及结果对主张的影响。数据区分不了时保留未决，不把未显著或拟合排序写成唯一机制。无需机械凑模型、负对照或扰动数量。
- **主张对应真实执行。** 样本单位、对比、协变量、基准、效应量和区间定义可从执行对象及所用记录核验。退出成功与模型有效分别记录；收敛、警告和失败从实际诊断提取，不能写死成功状态。独立核验要能发现报告、代码和JSON共同复制的同一错误。
- **委派分担主体分析。** 主 Agent 初始定向后、主体管线开工前，把至少一项支撑核心结论的实质分析交给原生 general-purpose 子 Agent。子侧承担对应读取、实现、调试与结果生成；主侧协调并定向核验，日志可连接委派时点、实际分析与采纳决定。末尾审稿不能替代早期分担。
- **复核改变交付。** 至少一项核心计算由另一执行者从原始输入独立编写并实际执行；另外核对分析定义与方法有效性。实质分歧有可重现的原因及修正，或在核心结论中保留未决范围。涉及效应、排序、单位或推断强度的修订同步到正文、摘要、表图与机器结果，不能只追加局限段。
- **当前证据与交付一致。** 主侧 working/analysis-state.md 能定位已确认事实、分工、未决问题、已采纳/未采纳结果、证据版本及报告位置。最终入口在干净目标目录实际重建终稿依赖的核心产物，核验合理容差与公共格式；声明的每项通过均有执行或审读证据。

## 资源与边界

使用当前题目的原始数据、公共说明、计算工具和原生 general-purpose 子 Agent。研究方法由问题与数据决定。主 Agent 只需先了解目标、文件结构、单位及依赖，再按问题拆分；大表读取、探索与局部调试交给对应分支，简短回执引用落盘原件。多个可独立分支可分别委派，并发上限不要求凑满。

主侧提前委派与状态维护要求不适用于子 Agent。子 Agent 是 leaf，亲自完成有界委派，不再派生或改他人的文件。原始输入与共享上下文只读；working/ 保存过程，output/ 按公共契约交付最终源码、结果、报告和必要复核证据。禁止读取历史答案、别题、隐藏评分资产或重建来源身份。

无数据或缺少关键元信息时说明可识别范围。工具或委派不可用时保留原始错误，完成可执行部分并标记未覆盖条件；自检如实命名，不冒充独立复核。不预设必须得到显著性或特定机制。

## 输出规格

加载与执行记录如实区分“已由工具返回正文”“仅见于索引”“尝试失败”和“尚未读取”。只把实际收到的文件正文列为已加载；自动注入的上下文可注明注入来源。不得把完整索引抄成已读清单，也不能把他人执行写成自己执行。通过声明连接实际命令、工具结果或已检查产物；没有证据则保留未验证。模块按职责选读，无须为记录完整而机械读全。

公共报告中的核心主张连接研究对象、原始输入、实际计算、最终结果定位及支持范围。复核证据包含独立执行者、输入、命令、最终文件、差异和影响，可合入现有报告或摘要。主侧状态只作短导航，详细历史与数据留在原件；交付读者无需访问聊天或工作记忆即可追溯核心结论。

真实返工中曾出现：主体分析后才派复核；未读最终子产物便整合；把未进入模型的变量写成已控制；状态间p值挤掉其他公开比较；分组重算冒充留出；收敛标志写死为真；均值差区间误标成标准化效应量区间；追加审计却保留失效结论。另曾出现只读取部分参考文件，却把整个索引列为已加载；完成记录也必须接受原始工具轨迹核验。这些风险由相应模块验收，不给当前题目预设答案。
