# 公开研究问题的覆盖与估计定义

目标是完整回答公共研究目标，不以显著性、报告长度或 Finding 数量定义完成。主 Agent 在初始定向时从 ResearchObjective、DATA_GUIDE 与公共契约提取实质问题，主体执行者复核数据能否支持这些问题。不要读取隐藏评价资料、来源答案或历史结果来选择目标。

在 working/analysis-state.md 中维护一个紧凑覆盖表，已有状态文件就合并，不另建重复台账：

| 问题ID及公共来源 | 要比较的对象/条件/变化 | 估计定义、参照与独立单位 | 执行者和证据定位 | 当前回答/缺口与影响 |

覆盖按研究维度判断，而非按文件数判断。同一文件可能支持多个问题；多个文件也可能只支持同一问题。检查同组内变化与组间差异、绝对量与相对基准、局部模式与整体趋势是否回答不同问题。对公开要求的动态、剂量、空间或尺度问题，选择能描述过程或边界的量，不把所有问题都改写成某个系数的p值。具体指标及方法由任务决定，不要求每题固定使用同一组统计量。

每个核心量能回答：描述谁、在哪个条件和范围、参照是什么、如何汇总、单位是什么、不确定性针对哪个估计量。比值的分母、差值的方向、归一化基准、连接率的统计对象须明示。名为相同 replicate 的记录是否为同一生物/实验单位，需元信息支持；跨组或跨表编号相同不能自动建立配对。

主体委派覆盖有界问题，而非“把所有表跑一遍统计检验”。主 Agent 保留整合责任：任何被省略的公共比较都能找到原因，任何已回答问题都能定位实际结果。阴性、反向和未决回答同样保留；不得只登记显著分支，也不得把缺分析直接登记为无效应。

最终验收由公共目标重新核对覆盖表和报告。状态必须是有证据的已回答、条件性回答、被反驳、未决或不可执行；不可执行注明尝试与设计/资源证据、缺口对哪些结论有影响。每个公开要求都有交代才算覆盖完整，但交代限制不等于检验已经完成或结论已被验证。
