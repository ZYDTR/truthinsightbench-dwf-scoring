# 数据与研究设计

需要得到一个可审计的分析对象，而不是仅有成功读取文件的代码。

对与科学问题相关的全部文件组，查明变量、单位、维度、采样顺序、坐标和派生关系。用数据检查说明文件与实际内容是否一致；排序、连接和去重依据须明确。原始记录、汇总值、插值值和理论输出分别标识。

确定独立证据单位。记录观测如何嵌套于来源、实验、个体、时间或计算条件，并让重采样、留出和不确定性估计遵守这种结构。独立单位数量不足时报告限制，不用更密集的网格或更多测量列制造样本量。

在解释效应前检查设计覆盖：哪些变量共同变化、哪些组合没有观测、哪些对比只有某一来源支持。对年龄、区域、条件、方法或其他因素的影响，区分可估计的对比与设计上无法分离的效应。模型系数存在并不代表因果或机制可以识别。

缺失、极端值、非正值、排除和变换需要明确理由及可恢复到原始记录的轨迹。替代处理方式若可能改变结论，保存敏感性结果。没有缺失或排除也应由代码检查证明。

速率、比例、归一化量和导数特别需要检查数学共享项：解释变量是否出现在响应变量定义中？两份结果是否由同一输入转换得到？据此区分数据一致性检查与独立科学证据。

报告对模型的描述须可从实际执行对象验证。涉及回归或分组比较时，核对实际设计矩阵的列、截距、编码基准、可估计对比和秩；仅计算出某变量不代表已纳入模型。样本不平衡或组合缺失时，使用成立的估计定义，并说明哪些效应无法分离。编号是否代表同一独立来源，需依据元信息验证。

单位在原始轴、转换、估计和最终标注之间保持一致；倒数、导数、对数与归一化改变单位或定义时，保存转换关系。对关键量给出独立的量纲或尺度核对，避免代码、JSON 和报告共享同一个错误标签。输入提供的误差、重复测量与依赖结构需要进入相应不确定性分析；缺失时明确哪些结论仅为条件性描述。

主 Agent 应能从保存的脚本和样本说明回答：当前估计描述谁、用了哪些记录、独立信息有多少、哪些对比超出了数据支持。

拟合状态直接读取实际结果对象，并保留警告、异常、可估计性诊断及采用该结果的依据。进程退出0不代表模型收敛；不能在序列化时写死 converged=true 或清除失败后仍保留有效模型结论。替代方法成功时保留前次失败及更换理由。

效应量与区间必须针对同一估计定义。原始均值差、标准化差、比值与对数比的区间分别标注；同一个数值标签在报告、代码和JSON中一致仍可能共同错误。重采样按已确认的独立单位进行，不把同一轨迹/来源的重复行当作额外独立样本。
