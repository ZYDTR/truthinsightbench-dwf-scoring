# 原生委派合同

目标是使子 Agent 无须猜测路径、职责或完成状态，就能独立完成有价值的工作。主 Agent 使用实际原生 Agent 工具与 general-purpose 类型，模型继承本轮配置；平台并发上限是边界，实际数量由任务价值决定。

## 提前分担主体分析

主 Agent 的初始定向足以识别研究问题、主要输入、数据结构和依赖即可。编写或执行综合主体分析管线之前，把支撑核心结论的实质分析交给子 Agent；分析分支的原始读取、方法实现、局部调试与结果生成都属于该执行者的工作，而不是等主侧算完后重复一遍。

按可独立判定的问题、数据依赖或竞争方法划分责任，通常可拆出数据结构与可识别性审查、主分析分支、替代解释或稳健性分支。至少一项须承担核心分析，不能全部是审稿、格式整理或最后复算。存在多个独立分支时分别派发；共同前提未确认时，让后续分支等待该前提的已检查结果。主 Agent 保持研究设计与整合职责，仅补做无法合理分离的有界缺口，并记录原因，不与子侧平行重写同一管线。

原生委派失败时保留错误，完成可亲自完成的工作并标记提前委派条件未满足。真实任务无法拆分时记录问题依赖及理由；不得用虚设子任务制造达标记录。

## 每项委派必须具备的信息

| 字段 | 可验证要求 |
|---|---|
| 角色与问题 | 明确这是 leaf 子任务；负责的主体分支或复核问题、研究边界、与其他执行者的接口可辨，假设与事实分开。禁止再派生 Agent、会话或模型进程。 |
| 项目与输入 | 项目根绝对路径、允许读取的原始文件、比较所需的定义和单位。独立探索可先不给主结论，数值复核可给报告值。 |
| 必读上下文 | 写出根目录下 context/INDEX.md、.claude/skills/scientific-evidence/SKILL.md 及本任务参考模块的完整路径。要求成功读取后再分析。 |
| 独占产物 | 专属目录、保存的源码与结果、预计命令；不得覆盖主报告或其他执行者文件。支撑终稿的材料须能纳入公共输出目录。 |
| 完成条件 | 本次应解决的具体问题、真实执行证据、比较与未决事项；结果如何供主侧整合可辨。先保存最终文件，再发完成回执。 |

子 Agent 路径读取失败时依据已给项目根纠正，保留失败，不把尝试读取当作加载完成。模块按用途选择：原始数据审计用 data-design；竞争解释与假设审查用 inference；数字复算和报告审计用 verification。无须让每个子任务阅读全部模块。

委派正文提供裁剪后的任务合同和必要路径，子侧自行按需读取输入；不粘贴完整主历史、全部数据或未经审查的主报告。可复用已核验的读取接口与定义，但明确其假设和版本。大量探索与调试输出留在子侧和产物文件中，回执给出简短结论、风险和准确定位；主侧依据这些定位读取关键源码与结果，既不盲信摘要，也不批量重读整套探索日志。

## 复核的独立性

至少一项关键复算要从原始输入独立编写并执行。主 Agent 给出要检验的定义和主张，同时允许复核者指出定义本身有问题；不要把主实现的所有方法选择都写成复核者必须接受的答案。

提前委派的分析执行者不能把重跑自己代码称为独立复核。选择另一个执行者核查其核心计算；可在已有分工中安排交叉核查，由主 Agent 直接布置，子 Agent 不向其他子任务派工。

方法审查关注样本单位、依赖、混杂、零假设和结论范围，可与数字复算同一子任务完成，但需分开报告。复核者先保留独立结果；若为定位差异再读主源码，记录何时、为何解除实现盲态，不把之后的一致当成完全盲态验证。

## 最终结果交接

子任务回执包含已读取模块、实际执行命令、最终源码/结果路径与版本、主要结果及支持范围、真实错误与未决问题。完成后若再修订，标为新版本并通知主 Agent 重新读取。

主 Agent 将执行者的完成状态与最终落盘文件对应起来，再阅读关键源码与结果。处理中结果只能用于协调；单纯文件存在或子 Agent 自报通过不能关闭复核。无需向已完成的子任务反复发送泛化的“继续”；追加工作应写清新的有界问题和受影响产物。

主 Agent 在 `working/analysis-state.md` 登记已完成待审、采纳或未采纳状态，采纳时同步报告位置与权威证据版本。子结果改变主张时同时更新下游产物；只在聊天中总结、只列出子脚本路径，都不能代替整合。

方法审查的交付应指明受影响的核心主张和证据位置，给出可核验的修正依据或未决范围。分析者与复核者都需对实际代码中的口径负责；主侧以原件裁决，不能把任一执行者的自报正确当成完成条件。

委派的有界问题应能连接公开目标覆盖表。分析分支负责实际主体估计；质疑分支关注遗漏的比较、最强竞争解释或验证设计，允许在主结果形成前给出独立判断。数量由真实分工决定，不机械凑角色。负责验证的执行者需区分独立实现与独立数据；主侧只依据实际分离证据关闭留出要求。
