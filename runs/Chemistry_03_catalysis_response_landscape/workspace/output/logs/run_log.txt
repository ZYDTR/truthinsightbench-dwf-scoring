REAL ERRORS ENCOUNTERED AND HOW THEY WERE HANDLED
  E1. 03_core.py first run raised KeyError('series') when the two transfer frames were
      merged with overlapping key names. Fixed by renaming the join key to '_k' before
      the merge.
  E2. 03_core.py's first SS implementation omitted the grand-mean offset, giving
      eta^2 values above 1 (main eta^2 = 1.175) and a negative residual. Detected because
      the three terms failed to sum to 1. Fixed by computing the modelled deviation as
      (X @ beta) directly under sum-to-zero coding, which is only valid for a balanced
      design. Residual after the 3-way term then fell to ~1e-12 and the terms sum to 1.0.
  E3. A permutation null that reshuffled the response within (A,B) cells was applied to
      the 3-way interaction SS and returned a null mean (378.2 for f6) far ABOVE the
      observed value (103.8), i.e. p = 1.0 in the wrong direction. This is an invalid
      null for an unreplicated factorial: reshuffling changes the cell variances rather
      than testing sparsity of interactions. The test was NOT silently dropped; it is
      preserved verbatim in evidence/05_interaction_inference.json under
      "failed_test_preserved" and reported in Result.md. It was superseded by Tukey's
      1-df non-additivity test and a Lenth-style contrast scan.
  E4. Full contrast-matrix regression on the 1430-row factorial exhausted the 120 s
      foreground timeout (the 3-way contrast block alone is 1080 columns). Replaced with
      the closed-form balanced-factorial SS identity. The replacement was validated
      against the regression result before use: closed form gives eta^2
      0.521105/0.324963/0.153931 for numeric_feature_6 versus the regression's
      0.5211/0.3250/0.1539, an exact match.
  E5. 04_robustness.py raised KeyError('series') twice on the transfer frame after the
      join key rename; the leave-one-series-out loop still referenced the old name.
      Fixed by using '_k' consistently.
  E6. 07_transfer_boundary.py timed out computing 50000 scipy Spearman permutations one
      at a time (37 s per 20k for one pair, 28 pairs). Replaced with the mathematically
      equivalent Pearson-on-ranks form vectorised as a single matrix product per pair
      (8 s per 20k), which completed all 28 pairs.
  E7. 08_artifacts.py raised KeyError('numeric_feature_5') because the panel-3/panel-4
      merge produced suffixed column names (_3/_4). Fixed by renaming columns before the
      merge.
  E8. 09_transfer_confound.py built a column name 'numeric_feature_R' by string
      substitution for the within-condition dispersion. Fixed by passing the real column
      names explicitly.
  E9. 10_figures.py raised a shape mismatch (7 vs 8) plotting the panel-4 rank block,
      which has 8 present rows but only 7 series. Fixed by slicing to the 7 shared series.
  E10. A background `until [ -s ... ]` waiter and a background pip install were left
      running past their windows; the waiter was superseded by a direct poll of the
      artifact file. No scientific step depended on either.
