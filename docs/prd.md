# Product brief

Goal: preserve all inputs required to score the first 27 released DWF submissions in one public GitHub repository, without modifying the live harness or exposing runtime credentials.

Success means the original scorer can dry-run all 27 exported run roots; each submission validates and has hash-bound registered inputs and frozen outputs; formal scoring can later run with an authorized judge endpoint.

Out of scope: rescoring the scientific results here, changing benchmark rules, or exporting active/unreleased tasks.
